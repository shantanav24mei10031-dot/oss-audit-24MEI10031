## 📌 Project Description
This repository contains 5 Bash scripts developed as part of the Open Source Software lab.  
Each script demonstrates core Linux shell scripting concepts such as loops, conditionals, file handling, and system commands.

---

## 📂 Scripts Included

### 1️⃣ System Identity Report
- Displays system information like:
  - OS Distribution
  - Kernel Version
  - Logged-in User
  - Uptime
- Uses commands like `uname`, `whoami`, `uptime`

---

### 2️⃣ FOSS Package Inspector
- Checks if a package (Git) is installed
- Displays version and details
- Includes open-source philosophy notes

---

### 3️⃣ Disk and Permission Auditor
- Audits important system directories:
  - `/etc`, `/var/log`, `/home`, `/usr/bin`, `/tmp`
- Shows:
  - Permissions
  - Owner & Group
  - Directory size

---

### 4️⃣ Log File Analyzer
- Analyzes system log files
- Counts keyword occurrences
- Displays last 5 matching lines
- Includes error handling

---

### 5️⃣ Open Source Manifesto Generator
- Takes user input
- Generates a personalized manifesto
- Saves output to a text file

---

## ⚙️ How to Run

Make scripts executable:
chmod +x *.sh
Run scripts:
./system_report.sh ./package_inspector.sh ./disk_auditor.sh ./log_analyzer.sh /var/log/boot.log error ./manifesto.sh
